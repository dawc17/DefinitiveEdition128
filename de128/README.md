# Definitive Edition 128

This folder is the mod itself. Copy it into Eclipse's `Mods` folder and keep the name `de128`, since that has to match the `id` in `mod.toml`.

`scripts/main.lua` is the entry point and loads everything in `scripts/content`. Art, audio, animations and models are in `assets`. The mod needs a Project Eclipse build that matches the core version in `mod.toml`.

See the [main README](../README.md) for what DE128 is.
